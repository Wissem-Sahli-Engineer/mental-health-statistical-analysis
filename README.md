# 📊 Statistical Analysis – Mental Health

## 📌 Project Description

This project focuses on a statistical analysis of factors influencing mental health.

The study was conducted using several statistical methods:

- 📈 Descriptive Statistics  
- 🔍 Principal Component Analysis (PCA)  
- 🧩 Multiple Correspondence Analysis (MCA)  
- 🌳 Hierarchical Clustering  

The analysis was performed using statistical software and data analysis libraries for data processing, visualization, and multivariate analysis.

---

## 💻 Code & Implementation

The project includes:

- Data import and preprocessing  
- Statistical summaries and visualizations  
- Computation of eigenvalues and explained variance  
- Extraction of coordinates, correlations, cos², and contributions  
- Generation of factor maps (variables and individuals)  
- Implementation of hierarchical clustering to identify groups  

The code was used to clean the dataset, compute statistical measures, and generate all graphical representations included in the report.

---

## 📊 Descriptive Statistics

The dataset was imported and analyzed.

The following descriptive analyses were performed:

- 👥 Distribution of respondents by gender  
- 🎂 Distribution by age group  
- 🎓 Distribution by education level  
- 🏠 Distribution by place of residence  
- 😴 Distribution of average sleeping hours  

---

## 🔍 Principal Component Analysis (PCA)

### 🎯 Objective
To study the criteria influencing mental health and group responses into main dimensions.

### 🛠 Steps Performed

- Analysis of eigenvalues  
- Axis selection (Kaiser criterion, cumulative inertia, elbow method)  
- Interpretation of variable coordinates  
- Analysis of variable-dimension correlations  
- Analysis of cos² (quality of representation)  
- Analysis of variable contributions  
- 📌 Variable factor map  
- 👤 Individual factor map  

---

## 🧩 Multiple Correspondence Analysis (MCA)

### 🎯 Objective
To analyze relationships between multiple qualitative variables related to habits and perceptions of mental health.

### 🛠 Steps Performed

- Eigenvalue analysis  
- Axis selection  
- 🗺 Modalities map  
- 👤 Individuals map  
- Interpretation of positive and negative associations between categories  

---

## 🌳 Hierarchical Clustering

### 🎯 Objective
To group individuals according to similarities in different mental health aspects.

### 📌 Results

- Identification of several clusters  
- Analysis of characteristic profiles for each group  

---

## ✅ Conclusion

This multidimensional analysis allowed the identification of the main factors influencing mental health within the studied sample.
